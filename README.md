# todo-cli

A tiny command-line todo manager written in Python.

## Features

- Add tasks
- List tasks
- Mark tasks as done
- Tasks stored in `~/.todo-cli.json`

## Usage

    python3 todo.py add "Buy milk"
    python3 todo.py list
    python3 todo.py done 1

## Requirements

- Python 3.8+
